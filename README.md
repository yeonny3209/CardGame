# Arcane Duel

유희왕 마스터 듀얼 스타일의 브라우저 트레이딩 카드 게임입니다. 모든 카드는 이 프로젝트용으로 새로 만든 오리지널 카드입니다.

## 플레이

배포 주소: https://yeonny3209.github.io/CardGame/

`main` 또는 작업 브랜치에 푸시하면 GitHub Actions가 테스트·빌드 후 `gh-pages` 브랜치로 배포합니다 (`.github/workflows/deploy.yml`).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 룰 테스트 + AI 대 AI 퍼즈 테스트
npm run build    # 타입 체크 후 dist/ 로 정적 빌드
```

## 구현된 룰

- **덱**: 메인 40~60장, 엑스트라 0~15장, 동명 카드 3장. 금지·제한·준제한 리스트(`src/deck/deck.ts`의 `BANLIST`).
- **턴 구조**: 드로우 → 스탠바이 → 메인1 → 배틀(스타트/배틀/데미지/엔드 스텝) → 메인2 → 엔드. 선공 1턴 드로우·배틀 불가, 패 6장 제한, 덱 아웃 패배.
- **배치 위치**: 몬스터를 소환·세트·특수 소환하거나 마법·함정을 세트·발동할 때 놓을 칸(몬스터 존·마법/함정 존 5칸)을 직접 고릅니다. 빈 칸이 하나뿐이면 자동 배치되고, 아직 아무것도 지불하지 않은 일반 소환·세트는 칸 선택 단계에서 취소할 수 있습니다.
- **소환**: 일반 소환·세트(턴당 1회), 레벨 5~6은 1장, 7 이상은 2장 릴리스하는 어드밴스 소환, 반전 소환, 표시 형식 변경(턴당 1회, 소환한 턴 불가), 자체 특수 소환 조건, 융합·싱크로·엑시즈·의식 소환. 엑스트라 덱·의식 몬스터는 정규 소환된 적이 있어야 소생 가능.
- **체인**: 스펠 스피드 1/2/3, 체인은 역순 처리, 두 플레이어가 연속으로 패스하면 처리. 카운터 함정에는 카운터 함정만 체인 가능. 세트한 턴에는 함정·속공 마법 발동 불가.
- **유발 효과**: 동시에 발생한 유발 효과는 턴 플레이어 강제 → 상대 강제 → 턴 플레이어 임의 → 상대 임의 순으로 체인(SEGOC). "~했을 때 발동할 수 있다" 효과는 마지막으로 일어난 일이 아니면 **타이밍을 놓칩니다**.
- **대상 지정**: 발동 시 대상을 정하고, 처리 시 대상이 이동했으면 효과가 적용되지 않습니다. 상대 효과의 대상 내성 지원.
- **무효**: 발동 무효(카운터 함정)와 효과 무효, 몬스터의 효과 무효 상태.
- **배틀**: 공격 선언 대응 타이밍, 리플레이, 뒷면 몬스터 반전 후 데미지 계산, 리버스 효과는 데미지 계산 후 발동, 관통, 전투 파괴 내성, 2회 공격, 직접 공격 효과, 전투 파괴는 데미지 스텝 종료 시 처리. 데미지 스텝에는 `damageStep` 효과와 카운터 함정만 발동 가능.
- **지속 효과**: 필드 마법·지속 마법/함정·장착 마법. 장착 대상이 필드를 떠나면 장착 카드는 묘지로, 지속 함정이 떠나면 그 효과도 사라집니다.
- **1턴에 1번**: 카드명 기준(hard)과 카드 개체 기준(soft) 제한.

아직 없는 것: 링크·펜듈럼 소환, 컨트롤 탈취, 소환 무효, 데미지 스텝 세부 규칙 일부.

## 카드 풀

4개 테마 + 범용 카드 67종. 테마끼리 자유롭게 섞어 덱을 짤 수 있습니다.

| 테마 | 속성 | 주요 전략 |
| --- | --- | --- |
| 엠버윙 | 화염 | 튜너 서치와 전개 → 싱크로 소환, 번 데미지 |
| 타이드콜 | 물 | 레벨 4 전개 → 엑시즈 소환, 바운스 컨트롤 |
| 클락워크 | 땅/기계 | 융합 소환, 관통·대상 내성 |
| 베일본 | 어둠 | 묘지 활용, 의식 소환, 효과 무효 |

범용 카드: 드로우, 제거 마법, 핸드 트랩(몬스터 효과 무효, 배틀 페이즈 종료), 카운터 함정, 리버스 몬스터, 범용 싱크로/엑시즈/융합 몬스터 등.

## 플레이 방법

- 메뉴에서 내 덱과 AI 덱을 고르고 **듀얼 시작**.
- 빛나는 카드를 클릭하면 가능한 행동(소환, 세트, 발동, 공격 등)이 표시됩니다. 묘지·엑스트라 덱은 칸을 눌러 열 수 있습니다.
- 체인·대상 선택·유발 효과 발동 여부는 보드 가운데의 안내창에서 고릅니다.
- **체인 확인: 자동**은 소환·공격·체인·데미지 스텝·상대 엔드 페이즈에서만 대응 여부를 묻고, **항상**은 발동 가능한 모든 타이밍에 묻습니다.
- **덱 편집**에서 필터(종류·속성·테마·분류)와 검색으로 카드를 찾아 추가하고, 덱 코드로 덱을 공유할 수 있습니다. 덱은 브라우저에 저장됩니다.

## Android 앱 (APK)

휴대폰에서 설치해 오프라인으로 플레이할 수 있습니다.

- **내려받기**: https://github.com/yeonny3209/CardGame/releases/tag/apk-latest 의 `ArcaneDuel.apk`
  (푸시할 때마다 GitHub Actions가 빌드해 이 릴리스를 갱신합니다).
- **설치**: 휴대폰에서 APK를 열고, 안내에 따라 "이 출처의 앱 설치 허용"을 켠 뒤 설치합니다. Android 8.0(API 26) 이상.
- **오프라인**: 게임 전체가 APK 안에 들어 있고 앱은 인터넷 권한을 요청하지 않습니다. 비행기 모드에서도 동작하고, 만든 덱은 기기에 저장됩니다.
- **구조**: `android/`는 WebView로 게임을 띄우는 최소한의 앱입니다. 웹 빌드(`dist/`)를 `assets/www`에 복사해 `https://appassets.androidplatform.net/`라는 가상 주소로 제공하며, 그 밖의 요청은 모두 차단합니다.
- **서명 키**: `android/app/arcane-duel.keystore`는 새 빌드가 이전 설치 위에 덮어써지도록 서명을 고정하는 용도이며 **비밀이 아닙니다**. 스토어에 올릴 때는 직접 만든 키로 바꾸세요.

직접 빌드하려면 JDK 17과 Android SDK가 필요합니다.

```bash
npm ci && npm run build
rm -rf android/app/src/main/assets/www && cp -r dist android/app/src/main/assets/www
cd android && ./gradlew assembleRelease   # android/app/build/outputs/apk/release/app-release.apk
```

## 구조

```
src/engine/   룰 엔진 (UI와 독립)
  types.ts      카드·효과·이벤트·요청 타입
  core.ts       듀얼 상태, 카드 이동, 공격력/수비력 계산, 이벤트
  flow.ts       턴·페이즈, 발동 가능 판정, 체인, 유발 효과, 배틀
  context.ts    카드 스크립트가 쓰는 API (서치, 파괴, 특수 소환 등)
  materials.ts  융합·싱크로·엑시즈·의식·릴리스 소재 조합
src/cards/    카드 데이터베이스와 효과 템플릿
src/deck/     덱 규칙, 금지 제한, 스타터 덱, 덱 코드, 저장
src/ai/       휴리스틱 AI (공개 정보만 사용)
src/ui/       메뉴, 듀얼 화면, 덱 빌더
tests/        시나리오 룰 테스트, AI 대 AI 퍼즈 테스트
```

엔진은 비동기 `Controller` 인터페이스로 플레이어에게 선택을 요청합니다. 사람(UI)과 AI, 테스트 스크립트가 같은 인터페이스를 구현합니다.

### 카드 추가하기

`src/cards/pool.ts`에 정의를 추가하면 덱 빌더와 게임에 바로 나타납니다.

```ts
monster({
  id: 'my_card',
  name: '새 카드',
  attribute: 'LIGHT', race: 'Warrior', level: 4, atk: 1800, def: 1000,
  text: '이 카드가 일반 소환에 성공했을 경우에 발동할 수 있다. 1장 드로우한다.',
  effects: [{
    label: '1장 드로우',
    type: 'trigger',
    event: 'summoned',
    eventFilter: summonedSelf('normal'),
    opt: 'hard',
    resolve: async (ctx) => { ctx.draw(1); },
  }],
}),
```

효과 종류는 `ignition`(기동), `quick`(유발 즉시), `trigger`(유발), `activate`(마법·함정 발동), `continuous`(지속), `procedure`(특수 소환 조건)입니다. `cost`, `target`, `condition`, `opt`, `damageStep`, `when`(타이밍을 놓칠 수 있음) 등을 조합해 효과를 만듭니다.
