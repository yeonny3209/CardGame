# 밸런스 기준

## 기준 시점
"OCG 9기 중~후반"을 **①② 형식 카드 텍스트, 링크 소환 도입(마스터 룰 4) 이후, 약 2018~2019년**으로 해석했습니다.
이 시기의 특징을 다음과 같이 반영했습니다.

- 카드명 기준 1턴에 1번(하드 OPT)으로 제한된 엔진, 핸드 트랩, 소수의 범용 무효 카드
- 무조건적인 드로우·전체 파괴는 금지, 소생·강력 대응 카드는 제한
- 스탯 상한: 일반/효과 몬스터는 레벨별 공격력 상한을 둠 (`tests/balance.test.ts`)

## 금지·제한 (`BANLIST`)
이 프로젝트의 카드는 모두 오리지널이므로, 각 카드가 실제로 대응하는 카드의 등급을 따랐습니다.

| 등급 | 카드 | 대응하는 실제 카드 |
|---|---|---|
| 금지 | gen_insight, gen_cataclysm | 욕심한 항아리, 번개/암흑계의 도사 |
| 제한 | gen_seconddawn, gen_edict, gen_barrier, gen_thunder, gen_twisters, gen_prison, gen_hunter | 사자생, 신의 심판, 격류장, 번개 폭풍, 트윈 트위스터즈, 차원 감옥, 상간 |
| 준제한 | gen_whirlwind, gen_starfall, gen_exchange, gen_reincarnation, gen_chalice, gen_bottomless, gen_scout | 폭풍, 분쇄, 자비의 천사, 몬스터 환생, 금단의 성배, 바닥없는 구멍, 토마토 |

## 범용 카드 추가 (`src/cards/staples.ts`, 25종)
- 범용 상급 일반 몬스터: gen_serpent, gen_wyvern, gen_ifrit, gen_archmage, gen_dragoon, gen_blackdrake
- 번 데미지 화염/기계족 효과 몬스터 (Lv1~4)
  - Lv1 도화선 인형: 상대에게 파괴되어 묘지로 갔을 때 800
  - Lv2 열풍 톱니 병정: 자신 엔드 페이즈, 다른 화염 몬스터 × 200
  - Lv3 용광로 정비병: 일반 소환 시 묘지 화염 몬스터를 제외, 레벨 × 200
  - Lv4 열폭주 포병: 소환 시 상대 LP ≥ 자신 LP이면 800
- 핸드 트랩·마법·함정·기타 효과 몬스터 (gen_veiler, gen_crow, gen_thunder, gen_twisters, gen_negate, gen_prison, gen_armor 외)

## 테마 조정 요약
- 클락워크: 융합 마법 하드 OPT, 키메라 소재 제한과 공격력 보너스 상한, 타이탄 공격력 하향, 팅커 서치 후 패 1장 버림
- 엠버윙: 튜너 라인 보강
- 베일본: 의식 소환 소재로 묘지 몬스터를 제외 가능
- 선샤인: 아침새 Lv7→6(2400), 일륜룡 Lv8→7(2800)
